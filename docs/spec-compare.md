# 比較仕様

## 原則

**比較の単位は任意の2球。どの2球を比べるかはユーザーが選ぶ。**

アプリが「これがミスの球です」と判定して提示することはしない。2D姿勢推定ではフェース角も打点も映らず、「姿勢が他と違う＝ミスの球」というロジックは成立しないため。

代わりに、選ぶ操作を軽くすることで解決する。

## 比較相手の選び方

| 状況 | 操作 |
|---|---|
| 打った直後 | 「最新球 vs 基準スイング」が1タップで開く |
| それ以外 | スイング一覧のサムネイルから任意の2球を選ぶ |

最新球のショートカットは、比較対象を最新球に限定する意味ではない。常に任意の2球を選べる。

比較候補の自動提示は行わない（v1.1以降に「おすすめ」として再検討）。

## 基準スイング

ユーザー自身が選んだ1球を「基準スイング」としてピン留めし、以降の比較の既定の相手にする。v1では1本。

これはアプリが客観的に最良の球だと判定したものではなく、本人が比較の基準として選んだ1球である。UI文言でもそう読める表現にする。

## 比較の種類と既定の表示方法

| 比較の種類 | 典型的な場面 | 既定の表示 |
|---|---|---|
| 同一クラブ・同一セッション内（主用途） | 「今の1球だけ感触が違った、何が違う？」 | 重ね合わせ＋4コマ静止画 |
| 異なるクラブ・同一セッション | 「アイアンは打てるのにドライバーだけおかしい」 | 横並び＋チェックポイント静止画 |
| 同一クラブ・日をまたぐ（副次） | 「今日は変だ、調子が良かった頃はどうだった？」 | 重ね合わせ |
| 同一クラブ・長期（副次） | 3ヶ月前・半年前との変化の確認 | 重ね合わせ |

同一セッション内の比較では、クラブ・天候・服装・カメラ位置・体調がすべて揃っており、身体の動きの差分だけが残る。これが主用途である。

異なるクラブの比較では、アドレスの幅とボール位置の差は正常であることを画面上に明示し、誤って欠点と読ませない。

重ね合わせは同じ撮影アングル同士でのみ有効とする。アングルが異なる場合は横並びを既定にする。

## 表示方法

### 4コマ静止画比較

アドレス / トップ / インパクト / フィニッシュの4点を静止画で左右に並べる。ゴルフの指導が静止位置を基準に行われることと、ダウンスイング中のモーションブラーを避けられることの両方に合う。

**最も安く価値が高いため、動画の重ね合わせより先に実装する。**

### 動画の重ね合わせ

2球を半透明で重ねる。判別のため一方を寒色、他方を暖色にティントする（CIFilterのカラーマトリクス1つで足りる。人物セグメンテーションによる輪郭線表示は実装しない）。

位置は手動スライダーで微調整できるようにする。自動位置合わせはv1では実装しない（同一セッション内では端末が動かないため不要）。

### 横並び

クラブまたは撮影アングルが異なる時の既定。

### 残像重ね（v1.1以降）

複数球のばらつきを1枚に重ねる表示はPro候補。v1では実装しない。

## タイミングと現実的な使われ方

機能はどのタイミングでも制限しない。以下は禁止事項ではなく、実際に起きやすい使われ方の想定。

| タイミング | 起きやすいこと |
|---|---|
| 打った直後（立ったまま） | 最新球と基準スイングの重ね合わせ。1タップで開く |
| ブロックの合間（ベンチ） | スイング一覧から任意の2球を選んで比較、クラブ間比較 |
| 帰宅後 | 日をまたぐ比較、長期の振り返り |
