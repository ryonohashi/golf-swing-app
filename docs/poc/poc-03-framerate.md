# POC-03: フレームレートと発熱

POC-02と並行して実施できる。

## 確かめること

60fpsで比較に足りるか。120fpsが本当に必要か。

## 仮説

**60fpsで足りる可能性が高い。**

このアプリが比較するのはアドレス・トップ・インパクト・フィニッシュという身体の位置であり、インパクト前後のクラブヘッドの挙動ではない。トップ付近ではクラブはほぼ静止しており、60fpsで十分な時間分解能がある。

120fpsが効いてくるのはインパクト前後のクラブの解析だが、それは `product.md` で「示せないこと」として明示的に範囲外にしている。したがって高fpsのコスト（発熱・電池・保存・処理）を払う理由が薄い。

このPOCはその仮説を否定する材料が出ないかを確認するもの。

## やり方

1. 同じスイングを60fpsと120fpsで撮る
2. 4コマ（アドレス／トップ／インパクト／フィニッシュ）を抽出し、位置決めの精度に差が出るか比較する
3. 2球の重ね合わせを作り、60fpsの方が明らかに見劣りするか確認する
4. 同条件で発熱と電池消費を比較する

## 測ること

| 項目 | 内容 |
|---|---|
| 4コマ抽出の精度差 | 特にインパクトのフレームがどれだけずれるか |
| 重ね合わせの見え方の差 | 主観評価でよい |
| 発熱 | `ProcessInfo.thermalState` の遷移を記録 |
| 電池消費 | 60〜90分稼働での減り方 |
| ファイルサイズ | 1クリップあたり、およびセッション合計 |

## 発熱の測定（fpsとは独立に必要）

リングバッファ方式でもカメラと符号化は回り続けるため、連続録画をやめても熱の問題は残る。消えるのはストレージと後処理時間であって熱ではない。

- 直射日光下で60〜90分カメラを稼働させる
- `thermalState` が `.serious` / `.critical` に入るまでの時間を記録する
- 実機を複数台（世代違い）で確認する
- 画面暗転の有無で差が出るか確認する

`.serious` に入った時にfpsを落とす処理が意図通り動くかも合わせて確認する。

## 合否基準

- 60fpsで4コマ比較・重ね合わせが実用になること
- 60分の稼働で `.critical` に達しないこと。達する場合は、fpsの自動降格またはセッション長の上限で回避できること

## 決まること

CLAUDE.md の暫定値のうち、フレームレートが確定する。あわせて、発熱時のfps降格の閾値と、セッション長の上限の要否が決まる。
